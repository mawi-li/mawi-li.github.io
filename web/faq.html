Questions & answers

A little more clarity.

A few useful answers about the studio and its projects.

What is Mawi.li?+

Mawi.li is an independent studio developing Windows software, Android apps, websites and games.

Where can I find releases?+

Available releases are linked from their project entries in the catalogue. If a project has no release link, there is no download listed here yet.

Are all projects free?+

Pricing and licensing belong to each project. Check its published details before downloading or using it.

Does every project support Arabic?+

This website supports Arabic and English. Language support for individual products is specified in their own documentation.

How can I report an issue?+

Email the studio with the project name, version and steps to reproduce the problem.

Who runs the studio?+

Mawi.li is led by its founder. The focus here is on the studio and its projects.
